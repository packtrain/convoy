# Convex core conventions

Read `apps/web/convex/_generated/ai/guidelines.md` first — it is generated by
Convex and overrides training-data assumptions. This file covers only the
**project-specific** rules layered on top.

For domain folder layout, `errors.ts` catalogs, repo files, and the `ensure`
helper in depth, see [backend-development.md](backend-development.md).

## File naming

**camelCase for every file in `convex/`.** Convex module paths allow only
alphanumerics, underscores, and periods — hyphens fail to deploy.

```text
✅ convex/cli/lib/constants.ts
❌ convex/cli/lib/cli-constants.ts   (will fail to deploy)
```

Everywhere outside `convex/`, use kebab-case — see
[../code-style.md](../code-style.md).

## Always include a `returns` validator

```typescript
export const myQuery = query({
  args: { id: v.id("tasks") },
  returns: v.object({ /* ... */ }),  // REQUIRED
  handler: async (ctx, args) => { /* ... */ },
});
```

For void, use `returns: v.null()` and `return null;`.

Public vs. internal: `query`/`mutation`/`action` are exposed to clients;
`internalQuery`/`internalMutation`/`internalAction` are server-only.

When adding task fields, update `taskReturnValidator` in
`convex/tasks/lib/validators.ts`.

## Query rules

- **Never `.filter()`** — always `.withIndex()`. If you need to filter by another
  field, add an index for that access pattern.
- **Never sort in memory** — put the sort field last in the index and results
  arrive sorted. "Latest" selection must be index-backed: include the time field
  in the index and use `.order("desc")`.
- **Avoid N+1 queries.** Query the fact table once (e.g. sessions), then batch
  `db.get` the related docs with `Promise.all`. Don't loop endpoints → query
  sessions per endpoint.
- **Don't mutate shared arrays inside `Promise.all`.** Return per-item arrays and
  `flat()`/`map()` so ordering stays deterministic.
- Use `.unique()` for single-document reads.

```typescript
const tasks = await ctx.db
  .query("tasks")
  .withIndex("by_project_and_isDeleted_and_isArchived_and_listKey_and_rank", (q) =>
    q.eq("projectId", args.projectId).eq("isDeleted", false).eq("isArchived", false).eq("listKey", args.listKey)
  )
  .collect();
```

## Pagination

Use `.paginate()` with `paginationOptsValidator`, and **always** type the return
with `paginationResultValidator(itemValidator)`. Never hand-roll a paginated
return validator containing only `page`/`isDone`/`continueCursor` — Convex also
returns `pageStatus` and `splitCursor`, and omitting them causes a runtime
`ReturnsValidationError`.

```typescript
import { paginationOptsValidator, paginationResultValidator } from "convex/server";

export const list = query({
  args: { paginationOpts: paginationOptsValidator },
  returns: paginationResultValidator(itemValidator),
  handler: async (ctx, args) => {
    const results = await ctx.db
      .query("myTable")
      .withIndex("by_createdAt", (q) => q)
      .order("desc")
      .paginate(args.paginationOpts);

    // Spread to preserve pagination metadata when enriching page items.
    return {
      ...results,
      page: results.page.map((doc) => ({
        _id: doc._id,
        _creationTime: doc._creationTime,
        name: doc.name,
      })),
    };
  },
});
```

## Authentication

**Use the helpers in `convex/lib/access/auth.ts`. Never inline
`ctx.auth.getUserIdentity()` plus a manual `by_token` lookup in a function
handler** — the only sanctioned raw uses live inside the auth layer itself.

```typescript
import { getAuthenticatedUser, getAuthenticatedAccess } from "../lib/access/auth";

// Throws if unauthenticated. Supports both Clerk JWT and API keys.
const user = await getAuthenticatedUser(ctx, args.apiKey);

// When you also need the principal for permission checks:
const { user, principal } = await getAuthenticatedAccess(ctx, args.apiKey);
```

Optional variants — `getOptionalAuthenticatedUser`,
`getOptionalAuthenticatedAccess` — return `null` instead of throwing.

## Permissions

Two-level access: organization + project. **Org owners/admins have implicit full
access to all projects.**

Always use the helpers from `convex/lib/access/permissions.ts`; never write
inline membership checks.

```typescript
import { requireAuthorizedProject, requireOrgPermission } from "../lib/access/permissions";
import { OrgPermission, ProjectPermission } from "@/lib/authz/permissions";

await requireAuthorizedProject(ctx, principal, projectId, ProjectPermission.TASK_UPDATE);
await requireOrgPermission(ctx, userId, orgId, OrgPermission.PROJECT_CREATE);
```

The permission enums live in `lib/authz/permissions.ts`; the enforcement helpers
live in `convex/lib/access/permissions.ts`.

## Error handling

`ConvexError` for user-facing errors (surfaces as a clean UI message); plain
`Error` for system bugs.

```typescript
import { ConvexError } from "convex/values";
throw new ConvexError("User is already a member");
```

For guard-style validation use the fluent `ensure` helper from
`convex/lib/shared/ensure.ts`, with messages from the domain's `errors.ts`
catalog. Pick the most specific check — `.eq`/`.notEq` for equality (never
`ensure(a === b).isTrue(...)`), and `.isTrue`/`.isFalse` only for values that are
already booleans:

```typescript
const org = await ensure(getOrganizationById(ctx, args.id))
  .active(errors.ORG_NOT_FOUND, errors.ORG_DELETED);
ensure(invitation.status).eq(InvitationStatus.PENDING, errors.INVITATION_REVOKE_REQUIRES_PENDING);
ensure(trimmedSlug.length).between(2, 50, errors.ORG_SLUG_LENGTH);
// Checks: notNull/isNull, notDeleted/active/isNullOrDeleted, isTrue/isFalse,
// eq/notEq, gte/between, regex, satisfies (last resort)
```

## Typing IDs

`Id<T>` must constrain `T` to `TableNames | SystemTableNames` (matching the
generated `Id`), not `string`.

In CLI code, derive query result types from the Convex API with
`FunctionReturnType<...>` rather than hand-written loose types.

## Scheduling

```typescript
const scheduledId = await ctx.scheduler.runAfter(
  30 * 24 * 60 * 60 * 1000,  // 30 days
  internal.tasks.permanentlyDelete,
  { taskId: args.id }
);
```

## Untrusted input

Never type-assert HTTP or JSON-RPC input. Don't write `as SomeUnion` — validate
with an allowlist or type guard before passing values into Convex.

## Before writing a new function

Grep for the real function name first. Naming is not always what you'd guess
(e.g. `remove`, not `softDelete`; there is no `organizations.members.add`).
