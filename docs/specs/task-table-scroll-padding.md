# Task Table Scroll Padding

## Scope

- Full project task table list view
- Root-level inline "Add task" row at the bottom of the table

## Expected Behavior

- When the task table has enough rows to scroll, users can scroll past the bottom "Add task" row by a small amount.
- The extra scroll space keeps the add-task input from sitting flush against the bottom of the viewport while typing.
- Compact task tables, such as subtask lists inside task detail sidebars, do not add this extra bottom spacer.
