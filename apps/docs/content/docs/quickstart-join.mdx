To run AI threads on your machine, connect the Convoy CLI to your project.
You need an account with project access, the deployment's Convex URL,
Node.js and npm, and an installed, authenticated AI runtime.

Follow [Install and connect](/docs/cli) to install the CLI, approve browser
login, select a working folder, and send your first thread. When it works,
your profile appears online in the web app and the thread streams a response
from the runtime on your machine.

If your team needs a deployment first, start with
[Deploy Convoy](/docs/deployment). Contributors running the full stack
locally should use [Run from source](/docs/quickstart-source).

You can use [projects and tasks](/docs/using) or connect an
[MCP client](/docs/cli/mcp) without keeping a CLI bridge running.
