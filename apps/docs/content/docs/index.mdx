Convoy brings projects, tasks, and AI conversations into one web app. Use it
to organize work with your team, keep decisions beside a task, and send work
to an AI runtime on your own machine.

You can manage tasks without installing the CLI. To run AI threads, connect
a machine with the Convoy CLI and an installed runtime. The CLI executes the
work locally and streams the response into Convoy.

To work with Convoy tasks from an editor or agent, [connect an MCP
client](/docs/cli/mcp). MCP works independently of the CLI bridge.

## What Convoy includes

- Organizations and projects with explicit membership and permissions
- Tasks, Lists, comments, attachments, and Markdown or HTML artifacts
- AI threads with project agents, Skills, reusable prompts, and workflows
- A local CLI bridge for supported AI runtimes
- MCP tools and terminal commands for integrations and scripts

See [supported runtimes and deployment status](/docs/reference/roadmap) for
runtime capabilities and deployment validation limits.
