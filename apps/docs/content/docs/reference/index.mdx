This section is the dense reference cluster: catalogs and schemas rather
than narrative.

- [CLI command reference](/docs/reference/cli-commands) — every `convoy`
  command and flag in one place.
- [Config file (`config.toml`)](/docs/reference/config-toml) — full schema
  for `~/.config/convoy/config.toml`, including profile resolution order.
- [Environment variables](/docs/reference/environment-variables) — matrix
  of every env var and where it belongs (Convex dashboard vs. web host vs.
  local `.env.local`).
- [MCP tools](/docs/reference/mcp-tools) — every tool the Convoy MCP
  server exposes, with hand-maintained argument tables checked against the server's
  tool-definitions module.
- [Glossary](/docs/reference/glossary) — short definitions of terms used
  throughout the docs and the product.
- [Supported runtimes and deployment status](/docs/reference/roadmap)
  describes runtime capabilities and deployment validation limits.

One reference-style page lives elsewhere by design:
[`Keyboard shortcuts`](/docs/using/keyboard-shortcuts) stays with the
product docs it describes.
