Operational guidance once a deployment is live.
[`Deploy Convoy`](/docs/deployment) answers "how do I stand this up?";
this section answers "how do I keep it running?".

## Pages

- [Upgrading](/docs/operations/upgrading) covers moving a live deployment to
  a newer Convoy version.
- [Migrations](/docs/operations/migrations) covers widening the schema,
  running the migration, and narrowing it after verification.
- [Monitoring and logs](/docs/operations/monitoring-and-logs) points to the
  dashboard, CLI logs, and alert signals.
- [Backups and rollback](/docs/operations/backups-and-rollback) covers
  database backups, web deployment rollback, and schema constraints.
- [Scaling and limits](/docs/operations/scaling-and-limits) explains
  concurrency and backpressure.
- [Debugging](/docs/operations/debugging) helps locate a failure by symptom.

For a connected machine, see [Running the CLI long-term](/docs/operations/running-the-cli-long-term)
in the CLI section. The [FAQ](/docs/operations/faq) is in Getting started.
